🌡️ Temperature Converter

A simple and responsive web application that converts temperatures between Celsius (°C), Fahrenheit (°F), and Kelvin (K) instantly. This project demonstrates the use of JavaScript for real-time calculations with a clean and user-friendly interface.

🔗 Live Demo: https://harikaran-07.github.io/web-projects/temperature-converter/

🚀 Features

- Convert Celsius, Fahrenheit, and Kelvin
- Instant and accurate calculations
- Responsive design for desktop and mobile
- Simple and intuitive user interface
- Fast and lightweight web application

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

🎯 What I Learned

- DOM manipulation with JavaScript
- Temperature conversion formulas
- Form validation and user input handling
- Responsive web design
- Git and GitHub workflow
